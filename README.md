# Spare Parts Inventory (Python CLI)

Ein leichtgewichtiges Konsolen-Tool zur Verwaltung von Ersatzteilbeständen und Artikeldaten.

## Features
- **Lagerbestand anzeigen:** Übersichtliche Auflistung aller registrierten Artikel inkl. Preis und Bestand.
- **Artikelsuche & Hinzufügen:** Gezielte Verwaltung von Einzelartikeln mit automatischer ID-Generierung.

## Technische Details
- **Sprache:** Python 3.x
- **Konzepte:** Dictionaries, Listen-Operationen, Typ-Hinweise (Type Hinting), Funktionen und Kontrollstrukturen.

python main.py
